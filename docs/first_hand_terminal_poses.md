# Устойчивые состояния после переноса первой руки

Сбор предназначен для проектирования следующего движения правой руки.
Он использует обученную policy, настоящую физику MuJoCo Warp и текущие
возмущения задачи. Обучение сети и её веса не изменяются.

## Сбор

Из корня репозитория в окружении `teleopit`:

```bash
python -m train_mimic.scripts.collect_first_hand_poses \
  --checkpoint "logs/rsl_rl/g1_ladder_first_hand_motion/2026-10-02_18-08-19/model_10000.pt" \
  --output outputs/first_hand_pose_bank \
  --samples 64 --representatives 8 --num_envs 16
```

Каталог результата должен быть пустым. Seed по умолчанию 42, policy работает
детерминированно; гравитация и толчки по-прежнему случайны. Начальная поза,
критерии успешности и физические параметры берутся из текущей конфигурации.
При достижении лимита `--max_steps` неполный банк сохраняется с `complete=false`,
а команда возвращает код 2. Успех не подменяется ослаблением критериев.

Подпись эталона проверяется строго. При известном различии вычислительных
окружений можно явно добавить `--allow_reference_mismatch` для локальной оценки.
Это не подтверждает эквивалентность эталона обучению. Обе подписи и факт
несовпадения сохраняются в manifest; такой банк относится к текущему локальному
прогону. Для точного воспроизведения кластерного окружения сбор следует выполнять
там же с той же версией кода, библиотек, XML и JSON.

## Как исключается автоматический reset

Коллектор снимает состояние на импульсе `success_pulse` при переходе HOLD → DONE.
В текущем порядке `ManagerBasedRlEnv.step` command обновляется после проверки
терминаций, поэтому этот импульс появляется за один шаг управления до
автоматического сброса. Позу копируют и записывают немедленно. На следующем
возвращённом `done` история соответствующей среды очищается.

Кроме штатного успеха повторно проверяются:

- обе закреплённые кисти; левая на следующей перекладине, правая на исходной;
- контакты и допустимое положение обеих стоп;
- ошибка ориентации/положения корпуса, его линейная скорость;
- угловые скорости корпуса/таза, скорости суставов и талии;
- окончание контрольного толчка либо чистый эпизод, отсутствие активной силы;
- непрерывная допустимая устойчивость на всей сохранённой последней секунде.

Снимок не принимается, если история короткая, содержит разные эпизоды, потерю
устойчивости или неконечные координаты/скорости. Порог HOLD в самой задаче
остаётся 2 секунды непрерывной устойчивости и минимум 3 секунды удержания.

## Формат результата

- `manifest.json`: источник checkpoint и его SHA256, seed, подписи эталона,
  версии библиотек, порядок суставов и шести дорожек, параметры возмущений,
  список записей, выбранные представители и `nominal_id`.
- `scene.mjb`: точная скомпилированная модель симуляции, включая геометрию.
  Для чтения используйте совместимую версию MuJoCo, указанную в manifest.
- `states/state_NNNN.npz`: последняя секунда реального HOLD; последний кадр —
  выбранное состояние начала проектирования следующего движения.

В NPZ поля с историей имеют первую размерность времени: `qpos/qvel/qacc`,
`ctrl/actions`, `joint_pos`, `track_pos/track_quat`, опоры, перекладины, стадии,
скорости, гравитация и толчки. Кватернионы — wxyz. Дорожки:
left_hand, right_hand, left_foot, right_foot, pelvis, torso.
Отдельно сохранены конечные `eq_active` и `model_eq_data/solref/solimp`:
они нужны для корректного восстановления захватов, переставленных в этом эпизоде.
Координаты мира соответствуют сохранённой сцене.

Это набор физических состояний для IK и проектирования движения, а не полный
checkpoint работающей среды: внутренние буферы policy, сенсоров и FSM не
сохраняются. При будущем продолжении физического управления потребуется
согласованная инициализация этих компонентов. Реальные qvel не обнуляются.

## Выбор представителей

Первым выбирается медоид — реально достигнутая поза с минимальным средним
расстоянием до остальных. Затем выбираются позы, наиболее удалённые от уже
выбранных, чтобы покрыть наблюдавшийся разброс. Метрика учитывает положение
таза и корпуса (масштаб 3 см), их ориентацию (0.15 рад) и суставные углы
(0.2 рад). Знак кватерниона не влияет на расстояние.

Суставы и кватернионы не усредняются. Все представители — настоящие успешные
состояния; число различных геометрий поз может быть меньше числа записей.

## Предпросмотр в MuJoCo

Основная поза:

```bash
python -m train_mimic.scripts.preview_terminal_poses --bank outputs/first_hand_pose_bank
```

Конкретная запись и её история:

```bash
python -m train_mimic.scripts.preview_terminal_poses --bank outputs/first_hand_pose_bank --index 0 --history
```

Изображения выбранных поз и видео истории основной позы:

```bash
python -m train_mimic.scripts.preview_terminal_poses --bank outputs/first_hand_pose_bank --render_dir outputs/first_hand_pose_bank/previews
python -m train_mimic.scripts.preview_terminal_poses --bank outputs/first_hand_pose_bank --video outputs/first_hand_pose_bank/nominal_hold.mp4
```

Предпросмотр восстанавливает записанные состояния через forward kinematics.
Видео повторяет реальные измеренные кадры HOLD, но не запускает повторную
динамическую симуляцию и не содержит ещё не спроектированный перенос правой руки.
